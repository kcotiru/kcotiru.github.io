Work

Selected projects

Three things I built and shipped, and what each one had to get right.

  • UptimeKit — uptime and performance monitoring

    A self-hosted Pingdom alternative. A BullMQ worker checks endpoints every 30 seconds, logs outages with their duration and cause, and alerts Slack, Discord, or webhooks. A three-tier rollup pipeline (raw → hourly → daily) keeps the p50/p95/p99 latency charts fast and storage flat, with tenants isolated by PostgreSQL row-level security, SSRF blocking, and Vitest integration tests.

    Next.js 14 TypeScript BullMQ Redis Docker Supabase PostgreSQL

    Source

  • REST URL — URL shortening service

    A full-stack URL shortener with auto-generated nanoid codes, user-defined custom slugs, and atomic access tracking, served by a layered REST API (controller → service → repository) with Zod request validation.

    Node.js Express TypeScript React Vite Supabase PostgreSQL

    Source

  • Aquarium monitoring — undergraduate thesis

    A real-time monitoring system on Raspberry Pi pairing a CNN fish-behaviour recognition model with live water-quality sensors. Automated threshold alerts and a mobile dashboard let owners act on an abnormal reading or behaviour as it happens.

    Raspberry Pi CNN Sensors
